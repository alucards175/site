## 🔧 Установка и настройка

### Требования
- **Docker** 24.0+
- **Docker Compose** 2.0+
- **Git** (последняя версия)
- **Домен** с SSL сертификатом

### Быстрая установка
```bash
# 1. Клонируем репозиторий
git clone https://github.com/yourusername/hitmanki-store.git
cd hitmanki-store

# 2. Настраиваем окружение
cp .env.example .env
nano .env  # Редактируем настройки

# 3. Запускаем все сервисы
docker-compose up -d

# 4. Инициализируем базу данных
docker-compose exec backend php artisan migrate --seed

# 5. Готово! Сайт доступен по адресу
echo "Frontend: http://localhost:3000"
echo "Admin: http://localhost:8000/admin"
```

### Необходимые API ключи

#### Steam API
1. Переходим на https://steamcommunity.com/dev/apikey
2. Регистрируем домен
3. Копируем ключ в переменную `STEAM_API_KEY`

#### Qiwi Wallet
1. Регистрируемся на https://developer.qiwi.com/
2. Создаем проект для платежей
3. Получаем публичный и секретный ключи
4. Настраиваем webhook: `https://yourdomain.com/api/webhooks/qiwi`

#### ЮMoney
1. Переходим на https://yoomoney.ru/developers
2. Создаем приложение
3. Получаем Client ID и Secret
4. Настраиваем webhook: `https://yourdomain.com/api/webhooks/yoomoney`

#### Crypto Bot
1. Пишем [@CryptoBot](https://t.me/CryptoBot) в Telegram
2. Создаем приложение для платежей
3. Получаем токен бота
4. Настраиваем webhook: `https://yourdomain.com/api/webhooks/crypto`

# 1. Создаем бота через @BotFather

## 🔒 Система Provably Fair

### Как это работает
1. **Сервер** генерирует случайное число (server_seed)
2. **Клиент** предоставляет свое число (client_seed)
3. **Система** создает хеш от объединения этих чисел
4. **Результат** определяется на основе этого хеша
5. **Пользователь** может проверить честность после игры

### Проверка честности
```javascript
// Пример проверки открытия
const serverSeed = "abc123...";  // От сервера
const clientSeed = "xyz789...";  // От пользователя
const nonce = 1;                 // Номер игры

const hash = SHA256(serverSeed + ":" + clientSeed + ":" + nonce);
const result = parseInt(hash.substring(0, 8), 16) % 100;

// Результат определяет выигранный предмет
```
